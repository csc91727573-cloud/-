## ⚙️ 4단계 실무 설계 & 패브리케이션 파이프라인 (Design & Fabrication Pipeline)

본 포트폴리오는 단순한 이미지 나열을 넘어, 실무 설계 및 제작 전 공정을 검증할 수 있는 **4단계 워크스테이션 구조**로 구축되었습니다.

```
┌────────────────────┐      ┌────────────────────┐      ┌────────────────────┐      ┌────────────────────┐
│      PHASE 01      │      │      PHASE 02      │      │      PHASE 03      │      │      PHASE 04      │
│  CULINARY & LOGIC  │ ───▶ │  2D CAD DRAFTING   │ ───▶ │   3D SIMULATION    │ ───▶ │ FABRICATION DETAIL │
│ 공간 & 조리동선 기획 │      │ 2D 국가표준 실시설계 │      │  3D 모델 & 조명해석  │      │ 제작·결구 1:10 상세│
└────────────────────┘      └────────────────────┘      └────────────────────┘      └────────────────────┘
```

1. **PHASE 01. 공간 & 조리 동선 기획 (Spatial & Culinary Logic)**
   - 조리 전공 지식을 접목한 고객·서비스·조리 삼각 동선 분리 및 병목 차단 (유효 진입폭 1,200~1,800mm)
2. **PHASE 02. 2D 국가표준 실시설계 (2D CAD Drafting)**
   - AutoCAD 기반 1/50 축척 평면도, 천장 조명 배선도, 입면도, PVC Ø75 급배수 및 방수 트렌치 설비도 도면화
3. **PHASE 03. 3D 모델 & 조명 해석 (3D Simulation & Lighting)**
   - SketchUp 매싱 및 D5 Render를 통한 CRI 92+ 고연색성 조명, 3000K 간접 코브 조명, 남향 채광 시뮬레이션
4. **PHASE 04. 패브리케이션 & 결구도 (Fabrication & Detail)**
   - 천연석 45도 도메(Miter) 접합, 5축 CNC 곡면 목재 가공, 황동 매립 힌지 체결 등 1:10 제작 상세도 작성

## 💻 웹사이트 기술 아키텍처 (Tech Stack & Architecture)

- **Pure Static Architecture**: 서버와 데이터베이스 없이 GitHub Pages로 100% 영구 무료 호스팅
- **Frontend Stack**: Modern HTML5, Vanilla JavaScript (ES6+), Tailwind CSS CDN, Pretendard, FontAwesome
- **3D~2D Continuous Viewer**: 3D 투시도 렌더와 2D 캐드 도면을 하나의 연속 시퀀스로 탐색하는 고속 모달 엔진
- **Dynamic Inspector**: 각 프로젝트의 4단계 공정을 클릭 시 실시간으로 스펙, 유효치수, 시공 근거를 갱신
- **In-Browser PDF Generator**: 브라우저 내장 A4 가로 인쇄 엔진으로 A4 포트폴리오 북 및 1장 이력서 PDF 즉시 출력
- **Mobile Responsive**: 스마트폰(360~390px) 화면에서 텍스트 줄바꿈 및 글자 겹침 현상을 원천 방지한 반응형 레이아웃
